# News Portal Demo

Mở file `index.html` bằng trình duyệt để chạy.

Các file chính:
- index.html: Trang chủ
- category.html: Trang danh mục
- article.html: Trang chi tiết bài viết
- about.html: Trang giới thiệu
- style.css: CSS responsive
- script.js: Slider, menu mobile, search demo, newsletter
- *.svg: Ảnh minh hoạ tự tạo

Không dùng framework hoặc thư viện ngoài.
